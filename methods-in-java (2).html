CIS 101 · Introduction to Java

Methods are how a program gets things done.

A method is a named, reusable block of code. Some methods take information in through parameters, some hand information back out through a return value — and some do neither, or both. By the end of this lesson you'll be able to write all four combinations from scratch.

Step 1

The five parts of a method

Every Java method is built from the same five ingredients. Change any one of them and you change what the method can do.

01

Access modifier

Controls who can call the method. In this course we'll mostly use public.

02

Return type

void means "gives nothing back." Any other type — int, double, String — means the method must hand back a value of that type.

03

Method name

A verb-style name written in camelCase, like calculateTotal or printReceipt.

04

Parameter list

The inputs the method needs, written as type name pairs inside parentheses. Empty parentheses mean no input is needed.

05

Method body

The statements between { } that actually do the work — and the return statement, if one is required.

RULE

The one rule that matters most

If the return type is not void, every path through the method must end in a return statement that produces a value of that exact type.

Step 2

Four flavors of methods

Parameters and return values are independent choices — so together they create four combinations. Explore each one, then press Run to see it execute.

no parametersvoid — no return
public void printWelcome() {
    System.out.println("Welcome to Java!");
}

This method needs nothing from the caller and gives nothing back — it just performs an action. Think of it like a light switch: you flip it, something happens, and that's the whole interaction.

Try it: call printWelcome();

>
one parametervoid — no return
public void greetUser(String name) {
    System.out.println("Hello, " + name + "!");
}

This method needs one piece of input — a String called name — to do its job, but it still gives nothing back to the caller.

>
no parametersreturns a value
public String getCourseName() {
    return "Intro to Java";
}

No input is required, but this method must hand back a String. The caller can store that result, print it, or use it in another expression.

Try it: String course = getCourseName();

>
one parameterreturns a value
public int square(int n) {
    return n * n;
}

This is the most powerful combination: the method accepts input and produces output, so it behaves like a real function — input goes in, a value comes out.
